# Bulk Certificate Generator

A web-based application that generates certificates for multiple participants using a certificate template and a CSV file.

## Features

* Upload a certificate template
* Import participant names from a CSV file
* Preview certificates live
* Adjust name position, font size, and color
* Download individual certificates
* Generate certificates in bulk
* Download all certificates in a combined PDF

## Technologies Used

* HTML
* CSS
* JavaScript
* html2canvas
* jsPDF

## How to Use

1. Open the application.
2. Upload a certificate template.
3. Upload a CSV file containing participant names under a `Name` header.
4. Adjust the name position, font size, and color as needed.
5. Download individual certificates, all certificates, or a combined PDF.
